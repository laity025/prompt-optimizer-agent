# 实训6 执行测试

## 一、实训目标

1. 掌握本项目自动化测试体系的结构（单元 / 接口 / E2E / 前端单测 / 性能冒烟）。
2. 学会运行后端 pytest 测试并通过 `pytest-cov` 查看语句覆盖率报告。
3. 理解三类后端用例（单元、接口、迭代端到端）各自验证的业务能力。
4. 学会运行前端 vitest 单测，并验证 `tsc + vite build` 编译通过。
5. 学会执行性能冒烟脚本 `perf_smoke.py` 并解读核心接口响应时间。
6. 能够依据系统测试报告核对量化指标（得分提升 / 一致率 / 单轮耗时 / 成功率）。

## 二、实训内容

### 1. 背景知识

本项目采用「**变体生成 → 任务执行 → 质量评估 → 择优迭代**」核心链路。为保障交付质量，P6 阶段建立了三层自动化测试体系：

- **单元测试**：对纯函数/纯计算（分词、BLEU、ROUGE、关键词命中、格式合规、JSON 校验等）做隔离验证。
- **接口测试**：基于 `fastapi.testclient.TestClient` 驱动真实 ASGI 应用，验证注册/登录鉴权、任务与用例 CRUD、用户数据隔离、管理员越权拦截等。
- **端到端（E2E）测试**：通过 `set_mock_client` 注入 `FakeLLM`，在**无需真实 API Key** 的前提下跑通「变体生成→执行→评估→择优→版本→抽检→报表」完整迭代闭环，并验证「停止机制」。

关键设计：测试通过 `conftest.py` 在导入 `app` **之前**把 `DATABASE_URL` 指向独立临时 SQLite 库，彻底隔离，杜绝污染开发/部署数据库；每个用例结束后自动重置 LLM mock，防止 `FakeLLM` 泄漏到后续用例。

### 步骤7：验证量化指标

自动化测试用 `FakeLLM` 保证了逻辑正确性与可重复性；投入真实模型后需实测四项目标。本步骤给出真实冒烟参照与计算方法。

**操作命令：**

```powershell
# 配置真实模型密钥（backend/.env 填 LLM_API_KEY 后重启后端）
Get-Content "d:\trae_project\提示词自动迭代优化智能体\01.code\prompt_optimizer\backend\.env" | Select-String "LLM_API_KEY|LLM_DEFAULT_MODEL"
```

**指标计算与真实参照：**

1. **得分提升 ≥ 30%**：用优化后最优提示词与初始提示词分别在独立测试集执行，计算综合得分。示例（**特意构造的弱初始提示词**，非自动化断言，用于演示显著提升，不代表系统对已较强初始提示词的典型表现）：初始得分 **25 → 优化后 45**，提升 (45-25)/25 = **80%**，满足 ≥ 30%。
2. **一致率 ≥ 80%**：一致率 =（评审打分与人工分偏差 ≤ 1 分的样本数）/（抽检样本总数）× 100%。通过界面「人工抽检」打分后核算。
3. **单轮迭代耗时 ≤ 60 秒**：默认 4 变体 × 5 用例规模下实测整轮（变体生成 + 全量评测）平均耗时；采用并发执行 + 分批处理控制。
4. **任务执行成功率 ≥ 98%**：批量执行用例时统计成功调用占比 = 成功调用数 / 总调用数；超时重试（默认 2 次）提升成功率。

**成功标志：**
- 能给出四项目标的计算公式与达标判定。
- 提到真实 LLM 提升（25→45）作为「得分提升 ≥ 30%」的一项实测佐证。

## 五、故障排除

### 问题1：pytest 无任何测试被收集

**现象：** 运行 pytest 显示 "no tests ran" 或 0 项。

**解决方案：** 确认在 backend 目录执行且命令指向 `tests` 目录：
```powershell
cd "d:\trae_project\提示词自动迭代优化智能体\01.code\prompt_optimizer\backend"
python -m pytest tests -v
```

### 问题2：覆盖率工具缺失报错 `pytest-cov`

**现象：** 提示 `pytest: error: unrecognized arguments: --cov`。

**解决方案：** 安装 pytest-cov：
```powershell
pip install pytest-cov
```

### 问题3：前端 vitest 无法启动

**现象：** `npm test` 报 vitest 未找到。

**解决方案：** 在 frontend 目录执行依赖安装：
```powershell
cd "d:\trae_project\提示词自动迭代优化智能体\01.code\prompt_optimizer\frontend"
npm install
```

### 问题4：性能冒烟连接失败

**现象：** `perf_smoke.py` 报连接错误 / 超时。

**解决方案：** 确认后端已启动且端口一致：
```powershell
Get-NetTCPConnection -LocalPort 8000 -ErrorAction SilentlyContinue
# 应能查到 Listen 状态的监听; 若未启动，先运行 uvicorn 再执行脚本
```

### 问题5：真实 LLM 迭代一开始即失败

**现象：** 填了密钥后迭代仍在首轮失败。

**解决方案：** 检查 `.env` 中 `LLM_API_KEY` / `LLM_BASE_URL` / `LLM_DEFAULT_MODEL` 是否有效，改后重启后端（单测用 `FakeLLM` 不受影响）。
