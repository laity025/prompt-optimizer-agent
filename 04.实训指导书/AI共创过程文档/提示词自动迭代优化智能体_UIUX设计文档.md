## 一、设计原则

1. **清晰优于炫技**：界面围绕「创建任务 → 观察迭代 → 获取最优提示词」的主线组织；3D 图形与超大标题只承担品牌表达与层级划分，不干扰数据阅读。
2. **风格高度统一**：全站沿用同一套视觉语言——皇家蓝实心块、超大黑色粗体英文、中英对照标题、斜杠与 1px 细线、3D 蓝色流体环、黑色小人 IP，任何页面不得出现体系外的色彩与组件样式。
3. **过程可视化**：迭代的得分曲线、版本差异、评分理由是产品核心价值；得分以超大黑色粗体数字呈现，曲线为皇家蓝渐变折线，必须直观。
4. **关键操作低摩擦**：新建任务、开始迭代、导出报告三个高频操作在界面中有明确且可达的入口（蓝色胶囊主按钮）。
5. **状态可见**：任务的每一步（待运行 / 运行中 / 已完成 / 已停止）在界面中有明确状态标识与反馈。
6. **响应式**：布局在桌面（≥1280px）与移动端（≥375px）均可用；移动端缩小标题尺度、简化 3D 装饰，主操作不遮挡。

## 二、设计语言总览（全站风格基线）

> 本章为强制基线，后续所有页面与组件必须遵守。

### 2.1 风格关键词

`皇家蓝` `浅灰底` `超大黑字` `3D 流体环` `玻璃珠` `颗粒噪点` `黑色小人 IP` `斜杠` `细线` `实心蓝块` `大留白` `非对称`

### 2.2 品牌图形元素（照抄参考设计）

| 元素 | 形态描述 | 使用位置 |
|------|----------|----------|
| 3D 蓝色斜切椭圆环 | 皇家蓝→浅蓝紫渐变的倾斜椭圆环/圆盘，带柔和投影与细微颗粒噪点 | 登录页主视觉、空态背景、完成态插画 |
| 玻璃珠 / 渐变球体 | 高光玻璃球；辅助球体为珊瑚红 `#FF6571`、湖蓝 `#017BA9`、雾紫 `#916C7F`、玫粉 `#DF65A1` 渐变 | 登录页、空态、步骤引导点缀 |
| 黑色小人 IP | 不规则流体黑色块作「头发」、简笔侧脸、蓝色波浪线发丝、脸颊一颗 `#FD550C` 橘红圆点 | 品牌 Logo、空态、404、完成态、加载动画 |
| 超大黑色粗体英文 | Arial Black / Helvetica 900 字重，字距收紧，如 `PORTFOLIO`、`Contents`、`THANK YOU` 的尺度 | 登录页产品名、各一级页标题、关键数字 |
| 中英对照 + 斜杠 | 英文大标题后跟「／」斜杠与中文小标题，如 `Tasks ／ 任务`；中文标题下方配蓝色斜体小写英文，如 `界面设计 /interface` | 所有页面页头、卡片标题、步骤条 |
| 1px 细线 | 纯黑 10%-15% 透明的水平细线，用于标题下划线与版面横向切割 | 页头、分区、列表分隔 |
| 点前缀序号 | `·01 ·02 ·03`，超大黑色数字，中点引导，常骑跨在横向细线上方 | 步骤条、子页签、编号列表 |
| 实心蓝矩形块 | 近直角（4px 圆角）皇家蓝实心矩形，内部白色粗体文字，表示「当前/选中/激活」 | 侧边栏选中项、当前步骤、选中卡片、选中页签 |

### 2.3 版面气质

- 大面积浅灰留白，内容非对称排布，视觉重心偏左或偏右，不做居中对称的后台模板式排版。
- 数字即图形：得分、轮次、序号均以 60-96px 的 900 字重黑色数字直接作为版面元素。
- 装饰图形统一置于角落或左侧，使用柔和蓝调投影，禁止硬阴影、拟物高光与体系外插画。
- 所有渐变图形叠加 4%-6% 颗粒噪点（grain），消除塑料感。

## 四、核心页面设计

### 4.1 登录 / 注册页

**布局**：整页浅灰底 `#E9E9EB`，左右非对称双栏。

- 左栏（品牌区，约 55%）：3D 蓝色斜切椭圆环 + 玻璃珠组合主视觉，黑色小人 IP 立于环前；右下角放超大黑色粗体英文产品名（如 `PROMPT EVOLVER`，96px / weight 900 / 字距 -3px），标题下方一条 1px 黑色细线，线下排两行小字：产品中文名「提示词自动迭代优化智能体」与一句话定位「把上千次试错压缩成一次迭代」。
- 右栏（表单区，约 45%）：白色卡片（圆角 12px、1px 浅描边、无重阴影）。注册含邮箱、密码、确认密码；登录含邮箱、密码。卡片顶部黑色小人迷你图标 + `Login ／ 登录` 中英标题，标题下蓝色斜体小写 `/sign in`。

**交互**：
- 切换「登录 / 注册」标签，选中标签为实心皇家蓝小块白字。
- 注册提交后校验两次密码一致性与邮箱格式，成功则提示并自动登录跳转。
- 密码错误 / 账号不存在给出明确错误提示，不暴露系统内部细节。

**视觉规范**：底 `#E9E9EB`；输入框白底、1px `#D8D8DC` 描边、聚焦时皇家蓝描边 + 浅蓝外发光；主提交按钮为黑色实心胶囊（与参考稿「访问网站」黑胶囊一致，形成蓝-黑节奏）。

**状态**：空态（无输入）、错误态（格式错误/密码不匹配，输入框橘红 `#FD550C` 描边 + 小人 IP 皱眉变体）、成功态（进入主界面）。

### 4.2 任务列表页

**布局**：
- 页头：左上超大黑色粗体 `Tasks ／ 任务列表`（48px，weight 900），其下蓝色斜体 `/all optimization tasks` 与一条贯穿内容区的 1px 细线；右上「新建任务」皇家蓝实心胶囊按钮。
- 筛选行：状态筛选为文字标签组（全部 / 待运行 / 运行中 / 已完成 / 已停止），选中项为实心蓝小块白字；搜索框为白底浅描边、圆角 999px，前置黑色线性放大镜图标。
- 主体：任务卡片网格（桌面 2-3 列）。卡片为白底 12px 圆角、1px 浅描边、无阴影；卡内左上角为 `·01` 风格点前缀序号，任务名为黑色粗体 18px，类型用蓝色斜体小写英文 + 中文小标签；卡右侧当前最优分数用 40px 黑色粗体数字；底部一行放状态徽标、用例数、时间信息。
- 卡片悬停：描边变皇家蓝，左下角浮现小型蓝色流体投影。

**交互**：
- 点击「新建任务」跳转创建页。
- 支持按状态筛选、按任务名关键词搜索。
- 点击任务卡片进入该任务详情页。
- 状态徽标配色：待运行=灰色、运行中=皇家蓝（含三点加载动画）、已完成=绿色、已停止=橘黄；徽标为 4px 小圆角标签，色点 + 文字。

**状态**：空态——页面中央偏左放黑色小人 IP 仰望 3D 蓝色流体环的插画，配超大黑字 `Empty ／ 还没有任务`，下方蓝色胶囊「创建第一个任务」。

### 4.3 创建任务页

**布局**：分步表单，分三步——「基础信息 → 测试用例 → 确认并创建」。

- 步骤条照抄参考稿目录页：横向三列，每列由 `·01`（超大黑数字，骑跨在横向 1px 细线上）+ 中文粗体标题 + 蓝色斜体英文构成；**当前步骤为实心皇家蓝矩形块（4px 圆角），块内数字与标题全部反白**，已完成步骤数字变蓝，未到达步骤为浅灰字。三列对应：`·01 基础信息 /basic`、`·02 测试用例 /cases`、`·03 确认创建 /confirm`。

**步骤一 基础信息**：
- 任务类型选择：横向卡片式单选，含「文本生成 / 文本摘要 / 信息抽取 / 代码生成 / 自定义」。选中卡整体变为实心皇家蓝块、文字反白（对应参考稿蓝色高亮块）；选择预置模板后自动填充任务描述、评分标准、推荐自动指标。
- 字段：任务名称（必填，≤50 字）、任务描述（必填，≤2000 字）、优化目标（必填，≤500 字）、评分标准（必填，≤2000 字）、执行模型（可选，默认系统推荐模型）、评审模型（可选，留空沿用执行模型）、自动指标权重 / 评审打分权重（可选，默认各 0.5）、每轮变体数（可选，默认 4，范围 2-8）、最大轮次（可选，默认 10，范围 1-30）、并发数（可选，默认 2）、收敛参数（可选，默认连续 3 轮提升不足 0.5 分判定收敛）。

**步骤二 测试用例**：
- 支持逐条添加：每条含「输入」（必填）、「参考输出」（可选）、「关键词」（可选，用于关键词命中指标）。
- 支持 JSON / CSV 文件批量导入，上传区为浅灰底 1px 黑色虚线框，拖拽进入时虚线变皇家蓝、角落浮现小蓝球；上传后显示「解析成功 X 条 / 失败 Y 条」及失败原因清单。
- 用例列表支持删除、清空、可拖动排序。

**步骤三 确认并创建**：
- 展示任务摘要（类型、名称、用例数、参数配置），摘要以参考稿封底信息排版呈现：左标签右数值、1px 细线分行；点击「创建并进入任务」提交（蓝色胶囊）。

**交互**：上一步可返回修改；必填项未满足时提交按钮禁用（50% 透明度）并在字段下提示。

**状态**：预置模板选中态（蓝块反白）、字段校验错误态（橘红描边 + 错误文字）、文件解析完成/失败态。

### 4.4 任务详情页（迭代看板）

这是产品的核心页面，采用「概览 + 子页签」结构。

- 页头：`Board ／ 迭代看板` 超大黑色中英标题 + 细线；子页签为「概览 / 迭代过程 / 用例集 / 报告」，选中项为实心皇家蓝小块白字，未选中为黑字。

**概览子页**：
- 顶部信息区左侧为任务名（黑色粗体 24px）+ 类型蓝斜体小字 + 状态徽标；右侧为两组超大黑色数字，照抄参考稿年份排版——当前轮次/总轮次显示为 `03 ／ 10`（数字间斜杠连接），当前最优得分为 96px 黑色粗体数字，数字上方配蓝色斜体 `/best score`。
- 中部：最优提示词展示框（白底、1px 浅描边、圆角 12px、只读，右上角黑色复制图标按钮），下方并列「初始提示词」与「当前最优」的差异高亮对比，对比区顶部各压一条细黑线。
- 底部：操作区——「开始迭代」为黑色实心胶囊（待运行状态）、「停止」「冻结」为白底黑描边胶囊（运行中状态）、「导出报告」为皇家蓝实心胶囊（已完成状态）。按钮旁可点缀小型玻璃球装饰。

**迭代过程子页**：
- 得分曲线：皇家蓝折线（2.5px），线下填充皇家蓝→透明的纵向渐变并带轻微噪点纹理；X 轴为轮次、Y 轴为综合得分（0-100），目标分数为黑色 1px 虚线；最新数据点为蓝色发光圆点，悬浮显示黑底白字提示。
- 每轮版本列表：以 `Round ·01` 点前缀序号分隔，可展开查看任意一轮的变体集合、各变体得分（黑色粗体数字）、评审理由；支持「回退到此轮」（文字链接 + 斜杠图标）。
- 人工抽检入口：评估明细可展开任一「变体 × 用例」，展示自动指标与评审理由，并提供人工评分输入（1-10 分）与备注，用于校准自动评审一致率。
- 迭代完成后，曲线旁出现黑色小人 IP 举蓝球的完成插画。

**用例集子页**：表格展示当前任务的全部用例（输入/参考输出/关键词），表头为黑色粗体、行间用 1px 浅细线分隔；可增删，改动即时保存并用于下次迭代。

**报告子页**：照抄参考稿封底气质——顶部超大 `Report ／ 优化报告`，内容含最终最优提示词、版本差异对比、各轮评分理由汇总、优化建议；底部左右分置信息与「导出 Markdown」「导出 JSON」按钮（蓝色胶囊 + 白底黑描边胶囊），中央可放黑色小人 + `DONE` 标记。

**交互**：
- 「开始迭代」后，页面每 1.5 秒轮询后端进度接口，实时更新进度条（皇家蓝填充）与「已完成用例 / 成功 / 失败」计数。
- 运行中变体列表逐项变为完成态；失败项标红并悬浮显示错误原因。
- 得分曲线随每轮完成实时增长，新数字采用滚动跳动动效。

**状态流转**：待运行（无曲线，空态小人）→ 运行中（曲线增长 + 蓝色加载态）→ 已完成（曲线定型 + 小人 IP 完成插画 + 导出可用）/ 已停止。

### 4.5 （管理员）系统日志页

**布局**：页头 `Logs ／ 系统日志` 超大黑字标题 + 细线；表格展示系统运行日志（时间、用户、操作类型、结果、耗时、错误信息），表头黑粗体、行间 1px 细线；支持按时间范围与结果筛选，选中筛选项为蓝色小块。

**交互**：管理员可对非自身账号调整角色（普通/管理员）与启停账号；禁用前弹出确认对话框（白底、圆角 12px、标题黑色粗体），提示「禁用后该用户将无法登录，历史数据保留」。

### 4.7 资产门户页（仪表盘）

**布局**：页头 `Dashboard ／ 资产门户`（48px / weight 900）+ 蓝色斜体 `/asset overview` + 1px 细线。

- 统计卡区：横向 4-6 张白卡（圆角 12px、1px 浅描边），每卡含蓝色斜体小标题（如 `/tasks`、`/kbs`）、超大黑色粗体数字（40-56px）与中文标签——任务数、用例数、知识库数、端点数、工作流数、分享链接数，覆盖全资产维度。
- 趋势区：近 N 天（默认 7 天）趋势折线图（ECharts），皇家蓝 2.5px 折线 + 渐变面积，X 轴为日期、Y 轴为当日新增/执行量，含任务执行与调用量的双维度切换。
- 模型分布区：模型使用占比环形图（皇家蓝系渐变分段），悬浮显示模型名与占比数值；下方附「最近任务」列表（任务名、状态徽标、得分、时间，点击跳转任务详情）。

**交互**：顶部「刷新」按钮触发重新拉取；统计数字为 SQL 聚合结果，加载态用皇家蓝三点跳动；趋势图支持时间窗口切换（7 / 14 / 30 天）。

**状态**：空态——无任何资产时展示黑色小人 IP 仰望流体环插画与 `Empty ／ 还没有资产`，配蓝色胶囊「去创建任务」。

### 4.8 模型评测平台页

### 4.9 知识库（RAG）页

**布局**：页头 `Knowledge ／ 知识库` + 细线；左侧库列表、右侧库详情。

- 库列表（左）：白卡列表展示全部知识库（名称、文档数、块数、创建时间，数字为黑色粗体），顶部「新建知识库」皇家蓝实心胶囊；选中库为实心蓝小块白字。
- 库详情（右）：
  - **文档区**：文档表格（文件名、块数、状态），支持上传 .md/.txt 文件（拖拽上传区为浅灰底虚线框，拖入变蓝）与「一键导入示例语料」（从服务器 RAG_CORPUS_DIR 导入）。

**交互**：删除知识库前弹确认框（提示将解除引用该库的任务 RAG 配置）；上传文档实时刷新 doc_count/chunk_count（SQL 原子自增）；检索失败（嵌入模型不可用）时给出明确错误提示而非空结果。

**状态**：建库中 / 上传中 / 解析中为皇家蓝加载态；解析失败文档在表格中标红并悬浮显示原因。

### 4.10 在线服务页

**布局**：页头 `Service ／ 在线服务` + 细线；顶部统计行、中部端点列表、底部调用日志。

- 统计行：白卡展示端点总数、今日调用次数、累计调用次数（SQL 聚合，超大黑色数字 + 蓝色斜体小标题）。
- 端点列表（中）：白卡表格（端点名、绑定的任务/提示词快照、状态、今日调用、密钥），「发布端点」皇家蓝实心胶囊；行内操作：复制调用地址、轮换密钥、停用/启用、删除。
- 密钥管理：创建端点时生成 `sk-` 前缀密钥，首次展示明文一次，后续仅显示脱敏末四位；轮换密钥后旧密钥立即失效（HMAC 恒定时间比较鉴权）。
- 调用日志（下）：表格（时间、调用方 IP、状态码、耗时、模型、token 用量），支持按端点与状态码筛选；「限流规则」说明卡展示默认 60 次/分钟/端点，超限返回 429。

**交互**：密钥复制一键完成并 Toast 提示；限流触发时日志中标红 429 行并悬浮提示「触发限流，请稍后再试」。

## 六、关键流程

### 6.1 创建并运行任务

```
登录 → 任务列表 → 新建任务 → 选择模板/填写 → 添加用例 → 确认创建
     → 任务详情 → 开始迭代 → 观察得分曲线增长 → 迭代完成 → 导出/分享报告
```

### 6.2 迭代运行中断处理

```
运行中 → 用户点停止 → 确认弹窗 → 保存已产生结果 → 状态置为已停止
运行中 → 单用例失败重试耗尽 → 标记失败+原因 → 不影响其他用例继续
```

### 6.3 知识库导入与 RAG 检索

```
知识库页 → 新建知识库 → 上传文档 / 一键导入示例语料 → 解析分块（doc_count/chunk_count 原子自增）
     → 输入查询 → 嵌入向量 / 词法指纹检索 → 命中块高亮 → 评测来源支撑度 / 忠实度
```

### 6.4 在线服务发布与调用

```
在线服务页 → 发布端点（绑定任务最优提示词快照）→ 生成 sk- 密钥（明文仅展示一次）
     → 复制调用地址 → 外部以 X-Api-Key 头 POST 调用 → 限流 60 次/分钟拦截 429
     → 日志/统计 SQL 聚合 → 可轮换密钥 / 停用端点
```

### 6.5 模型评测与分享

```
模型评测页 → 选择多模型 + 用例 + 评分标准 → 开始评测 → 得分矩阵逐格填充
     → 推荐模型高亮 → 导出报告 / 分享报告（生成 /share/:token 链接）
     → 他人免登录访问公开报告页 → 分享中心可撤销，撤销后链接立即失效
```

### 6.6 多步骤工作流执行与步骤优化

```
工作流页 → 创建工作流（步骤指令模板 + {{input}}/{{stepN.out}} 占位符）
     → 执行工作流（步骤链式串联，占位符逐级解析）
     → 选择步骤 → 配置轮次(1/2/3/5) → 优化该步骤（多轮贪心，连续两轮无提升提前终止）
     → 对比每轮指令差异 → 采纳最优指令
```

## 七、适配要求

- 桌面（≥1280px）：浅灰底 + 左侧栏 + 内容区；侧边栏选中项为实心皇家蓝块白字；3D 流体环与小人 IP 全量展示。
- 平板 / 移动（<1280px）：侧边栏收起为顶部导航 + 抽屉；图表支持横向滚动；主按钮固定在便于触达的位置。
- 标题响应式：96px → 48px → 32px 三档缩放；移动端隐藏大型 3D 环，仅保留小人 IP 与小型玻璃球点缀。
- 登录页在移动端隐藏左栏主视觉的大部分，仅保留顶部小人 IP 与产品英文名，保持表单完整可用。
