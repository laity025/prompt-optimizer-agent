# 评分权重校准记录

| 项目 | 内容 |
|------|------|
| 文档版本 | V1.0.0 |
| 目的 | 记录综合得分权重校准方法与预期流程，支撑「自动评审与人工评分一致率 ≥80%」指标 |

---

## 一、校准目标

综合得分 = `w_auto × 自动指标得分 + w_judge × 评审打分分`。校准目标是找到使「合成综合得分」最贴近「人工金标准得分」的权重 `w_auto / w_judge`，同时保证评审判分与人工评分的一致率 ≥ 80%。

## 二、校准数据与流程

### 2.1 数据准备

- 从四类任务测试用例集的 **校验集（val）** 中各取若干条，作为权重校准样本。
- 对每条样本，同时采集三组分数：
  - **自动指标分**：如 ROUGE-L、BLEU、字段完整率等，归一化到 0-100。
  - **评审打分**：大模型按评分标准给出 1-10 分，换算到 0-100。
  - **人工金标准分**：人工抽检给出 1-10 分，换算到 0-100。

### 2.2 权重确定

- 在生成多组候选权重（如 w_auto=0/0.3/0.5/0.7/1.0）后，计算每种权重下合成得分与人工金标准的 **Pearson 相关** 与 **平均绝对误差**。
- 选取相关最高、误差最低的权重作为该任务的推荐权重，写入任务默认配置。
- 权重调整在 **val 集**上完成，不进 test 集，防止信息泄露导致过拟合。

### 2.3 一致率验证

一致率定义为「评审打分 1-10 分与人工金标准 1-10 分相差不超过 1 分」的样本占比，目标 ≥ 80%。

```
一致率 = (评审打分与人工分偏差 ≤1 的样本数) / (抽检样本总数) × 100%
```

若达不到 80%，回退到优化评分标准表述（如细化维度、补充示例）或调整评审提示词，再重新校准。

## 三、防过拟合原则

1. **集隔离**：dev（调优）→ val（调权/择优）→ test（最终验证），权重与变体只在 dev/val 上调整，test 仅验证一次。
2. **金标准**：人工评分作为唯一金标准，自动指标与评审均为代理，需持续抽检校准。
3. **抽检通道**：系统保留人工抽检接口，用户可对任意评估记录打分复核。

## 四、预期产物

- 每类任务的推荐权重表（供任务创建默认值）。
- 一致率评测记录（任务书任务 9 交付物，开发测试阶段产出）。

> 当前为评分基准设计阶段，实际校准数值在 **P3 评估模块开发 + P6 测试优化** 阶段落地执行。
