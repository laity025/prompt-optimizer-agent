# 前端开发实训语料库

**主题：** 提示词自动迭代优化智能体前端开发
**适用范围：** 前端开发、学习者
**版本：** v1.0

---

## Q: 本项目前端技术栈是什么？

**A:** 前端采用 React（界面框架）+ TypeScript（类型安全）+ Vite（构建与开发服务器）+ Ant Design 5（UI 组件库）+ TailwindCSS（原子化样式）+ Zustand（状态管理）+ React Router 7（路由）+ ECharts（得分曲线图表）。界面视觉按「皇家蓝作品集风格」（V2.0）组织：皇家蓝 #0E4AC3 实心块选中态、超大黑色中英对照标题、浅灰底 #E9E9EB、点前缀序号 ·01 与 1px 细线。

**标签：** 前端技术栈, React, TypeScript, Vite, Ant Design, TailwindCSS, Zustand, 皇家蓝

---

## Q: 前端目录结构如何组织？

**A:** 结构如下：
- src/main.tsx、src/App.tsx：入口与应用根组件
- src/api/：Axios 封装（自动附带认证头、统一错误处理）
- src/pages/：登录、任务列表、创建任务、任务详情、日志、用户管理等页面
- src/components/：得分曲线、进度条、版本差异对比等组件
- src/stores/：Zustand 状态管理
- src/types/：TypeScript 类型定义
- src/utils/：工具函数
- package.json、vite.config.ts

**标签：** 前端目录, pages, components, stores, types

---

## Q: 前端如何实现统一 API 调用？

**A:** 通过 src/api 的 Axios 实例统一封装：自动附带 Authorization Bearer token，统一处理响应结构与错误码，拦截 401 跳转登录，页面通过该实例调用后端 RESTful API，请求/响应类型与 src/types 对齐。

**标签：** Axios, API调用, token, 错误处理, 类型对齐

---

## Q: 前端如何管理页面状态？

**A:** 使用 Zustand 作为全局状态管理，用于跨页面共享的任务信息、进行中的迭代进度、用户会话状态等；局部页面状态使用 React 内置 state 管理，状态清晰、体积轻量。

**标签：** Zustand, 状态管理, 跨页面共享, 会话状态

---

## Q: 得分曲线组件如何实现？

**A:** 基于 ECharts 实现折线图，X 轴为轮次、Y 轴为综合得分（0-100），标注目标分数水平虚线；通过轮询进度接口获取每轮最优得分，随迭代完成实时更新曲线。

**标签：** 得分曲线, ECharts, 折线图, 轮询, 实时更新

---

## Q: 版本差异对比组件如何实现？

**A:** 用增删高亮方式对比初始提示词与当前最优：新增内容绿底高亮、删除内容红底删除线标注，直观呈现提示词在迭代中的改进。

**标签：** 版本对比, 差异高亮, 新增标注, 删除标注

---

## Q: 任务详情看板的子页签如何实现？

**A:** 任务详情页采用「概览 + 子页签」结构，包含概览、迭代过程（得分曲线+版本列表+人工抽检）、用例集、报告四个页签，通过路由或标签组件切换，各页签独立加载数据。

**标签：** 任务详情, 子页签, 概览, 迭代过程, 用例集, 报告

---

## Q: 前端如何实现迭代进度的实时展示？

**A:** 开始迭代后，前端每 1.5 秒轮询后端迭代进度接口，实时更新进度条与「已完成用例/成功/失败」计数；运行中变体列表逐项变为完成态，失败项标红并悬浮显示错误原因。

**标签：** 迭代进度, 轮询, 进度条, 失败展示

---

## Q: 前端如何适配响应式布局？

**A:** 桌面（≥1280px）采用侧边栏（选中项为皇家蓝实心块白字）+ 内容区布局；平板/移动（<1280px）侧边栏收起为顶部导航 + 抽屉，图表支持横向滚动，主按钮固定在易触达位置，登录页在移动端简化、标题 96px→48px→32px 三档缩放。

**标签：** 响应式, 移动适配, 侧边栏, 抽屉, 皇家蓝选中态

---

## Q: 前端如何保证类型安全？

**A:** 启用 TypeScript 严格模式，接口返回类型在 src/types 中统一定义，与后端 API 文档的字段一一对应；API 请求与页面组件均使用类型约束，减少字段拼写错误与运行期异常。

**标签：** 类型安全, TypeScript, 严格模式, 接口类型

---

## Q: 前端开发遵循哪些规范？

**A:** 规范包括：API 调用统一走 src/api 的 Axios 实例、页面状态用 Zustand、路由懒加载按需载入、注释清晰、与后端 API 文档字段对齐、对 AI 生成内容打标识等。开发技术文档提供详细约定。

**标签：** 前端规范, 统一调用, 路由懒加载, 告警标识

---

## Q: 前端如何与后端进行联调？

**A:** 前端通过 Vite 开发代理将 /api 请求转发到后端服务，前后端并行开发时约定接口契约（来自 API 设计文档），联调阶段核对字段与状态流转，支持跨域配置。

**标签：** 前后端联调, Vite代理, 接口契约, 跨域
