**回答**：根据[系统架构与技术选型语料库](file:///d:/trae_project/提示词自动迭代优化智能体/05.RAG语料/02-系统架构与技术选型语料库.md)，系统采用前后端分离的 B/S 架构，从下到上分为：

2. **后端服务层** - 基于 FastAPI 框架，包含认证、任务管理、变体生成与批量执行、自动指标、评审打分、迭代编排、报告生成等服务
3. **数据存储层** - 采用 sqlite3 存储用户、任务、提示词版本、测试用例与评测记录
4. **AI 能力层** - 对接 LLM API 实现变体生成、任务执行与评审打分，辅以 LangGraph 编排迭代循环

---

**用户问**：什么是 LangGraph，它怎么保证迭代不会无限跑下去？

**回答**：LangGraph 是用于构建有状态循环智能体应用的框架。在本项目的[后端开发实训语料库](file:///d:/trae_project/提示词自动迭代优化智能体/05.RAG语料/09-后端开发实训语料库.md)中，它把「生成变体→执行任务→质量评估→择优更新→终止判断」编排为状态图。

迭代不会无限运行的机制在于终止判断：每轮结束后检查三项条件，满足任一即退出——达到目标分数、最优得分连续若干轮提升不足（默认连续 3 轮每轮提升小于 0.5 分判定收敛）、或达到最大轮次上限。同时用户可手动停止，停止后支持断点续跑。
