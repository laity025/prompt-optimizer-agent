# API密钥申请实训语料库

**主题：** 提示词自动迭代优化智能体 LLM API 密钥申请与配置
**适用范围：** 开发者、学习者、运维人员
**版本：** v1.0

---

## Q: 为什么本项目需要 LLM API 密钥？

**A:** 本项目调用大模型 API 实现变体生成、目标任务执行与评审打分三项核心能力，需要有效的 API 密钥进行身份认证并计费，密钥就绪后才能进行后端开发联调。

**标签：** API密钥, 大模型, 变体生成, 身份认证

---

## Q: 如何申请 LLM API 密钥？

**A:** 本项目使用 OpenAI 兼容、国内直连的 LLM 服务。申请流程一般为：
1. 前往服务商官网注册账号
2. 完成实名认证与开通模型服务
3. 在控制台创建 API Key（不同服务商名称可能为 API Key / Token 等）
4. 保存密钥并配置到项目环境变量
可按服务商官方文档创建。

**标签：** 申请流程, API Key, 注册, 实名认证, 环境变量

---

## Q: 如何配置 API 密钥？

**A:** 密钥存入项目环境变量文件（.env），提供 .env.example 模板，填入 API 地址、Key、默认模型等；代码中通过配置模块读取，密钥不进版本库、不硬编码在代码中。

**标签：** 密钥配置, 环境变量, .env, 配置模块

---

## Q: 使用 API 密钥有哪些安全注意事项？

**A:** 注意事项：
1. 密钥务必保密，不提交到代码仓库、不对外泄露
2. 使用环境变量或密钥管理服务存储
3. 严格限制密钥权限与配额
4. 调用大模型 API 前对敏感的用户任务数据进行脱敏
5. 遵守服务商的使用规范与数据合规要求

**标签：** 密钥安全, 保密, 脱敏, 权限控制, 数据合规

---

## Q: 调用 LLM API 时如何控制成本与频次？

**A:** 为控制成本与频次，可控制每轮变体数、用例规模、并发数；对调用设置超时与重试；选用合适的模型档位；对大规模用例采用分批处理，避免不必要的重复调用。

**标签：** 成本控制, 频次控制, 并发, 超时重试, 分批处理

---

## Q: 密钥配置异常如何排查？

**A:** 常见排查：
1. 检查 .env 中密钥与地址是否正确、有无多余空格
2. 检查认证与权限是否开通对应模型
3. 检查网络是否可访问服务商接口
4. 查看后端日志中的鉴权与调用错误信息
5. 用最小脚本单独测试一次调用验证连通性

**标签：** 异常排查, 密钥错误, 鉴权失败, 网络, 日志

---

## Q: 大模型 API 的调用失败如何处理？

**A:** 批量执行与评审打分对超时/限流/接口错误自动重试（默认 2 次），重试仍败则标记该条为失败，记录错误原因（超时/限流/接口错误/非法返回），失败不阻塞其他用例与整体迭代流程。

**标签：** 调用失败, 重试, 失败标记, 错误原因, 不阻塞
